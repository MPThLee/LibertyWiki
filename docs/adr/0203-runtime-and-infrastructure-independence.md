# 실행물의 CPU 지원과 외부 인프라의 독립성

LibertyWiki 자체 실행물과 Docker 이미지는 ARM64와 x86-64를 지원한다. 프로젝트가 특정 오케스트레이터를 채택하거나 실행에 요구하지 않으며 배포·오케스트레이션은 사용자가 선택한다. 이미지 실행에 필요한 설정·포트·볼륨·헬스 체크·종료 계약을 문서화한다.

DBMS·OpenSearch·Redis·S3 서비스 등 외부 인프라의 CPU·OS·배포 방식은 LibertyWiki 자체 실행환경과 독립적이다. 양자가 같은 CPU나 같은 호스트에서 실행되어야 한다는 요구를 두지 않는다. 프로젝트는 각 앱 CPU 환경에서 외부 서비스와의 연결·기능·권한·장애 처리를 검증하며, 외부 제품의 실행환경을 프로젝트의 CPU 지원 범위와 결합하지 않는다.

근거: 사용자 Q24 수정과 Q27 질문에 대한 명시적 정정. 기존 아키텍처의 Compose 중심 배포 제안을 이 결정으로 대체한다. JVM 중심 런타임 ADR-101은 유지한다.

# 제품 범위와 실제 위키 이전의 경계

스킨에 관한 결정은 [ADR-0205](0205-product-skins.md)로 대체되었습니다.

MediaWiki 1.46.2 코어·기본 배포 확장·스킨 기능이 호환 범위이며, 리브레 위키는 실제 이전 검증 대상이다. 리브레 위키의 고유 기능 전체를 제품 요구로 자동 편입하지 않는다. 기본 배포 확장은 각각 manifest·버전·수명주기를 갖는 LibertyWiki 확장으로 개발하고 외부 확장과 같은 공개 SPI를 사용한다. LOCAL·S3 파일 저장과 서빙은 내장 기능이다.

제품 1.0.0 승인은 일반 문서 10만을 포함한 전체 문서 20만·등록 사용자 1만·DAU 100의 검증 프로파일로 판정한다. 전체 호환 게이트를 유지하며 ENWIKI 인증과 특정 위키의 실제 이전 승인은 분리한다. 파서·Lua·편집 왕복 변환의 위험 검증을 먼저 수행하고, 그 실측으로 구현 방식·필요 자원·공수를 재평가한다.

이전 승인은 기존 문법·이력·파일·URL·공개 숫자 ID의 의미 보존, 계정·기여·권한 연결, 최대 24시간의 쓰기 동결과 읽기 유지 리허설을 요구한다. 계정은 비밀번호 재설정 또는 관리자 소유권 확인으로 복구하며 기존 세션·API/봇 토큰·OAuth 승인·MFA 비밀값·복구 코드는 이관하지 않고 재등록한다. 확장 비활성화·제거는 데이터 영구 삭제와 분리한다.

근거: 사용자 인터뷰 Q2–8, Q12–13, Q15–17, Q20, Q25–26.
